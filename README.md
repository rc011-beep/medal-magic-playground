# Prueba de medallas

"Quiero agregar un entorno de prueba para el sistema de medallas en la aplicación. Por favor, crea un panel flotante de pruebas (o una pestaña de desarrollador) que incluya:

Botones para simular la completitud de cada uno de los módulos (Módulo 1, Módulo 2, Módulo 3, Módulo Final).

Un botón para 'Restablecer todo el progreso'.

Al hacer clic en un botón de simulación, la app debe actualizar el estado del módulo a 100%, desbloquear la medalla correspondiente en la sección de 'Mis Logros' y disparar un modal animado de felicitación con la medalla obtenida.

Guarda el estado de la prueba en localStorage para poder evaluar la UX al recargar la página."
